# Контрольная точка СЕТ 1.1.0

Дата: 29 октября 2026.

Эта контрольная точка фиксирует логику работы с черновиком и историей после изменений v1.1.0. Полный исходный архив включает текущие иллюстрации, полученные из базы v1.0.1; отдельный архив обновления для GitHub намеренно не включает изображения и каталог упражнений, чтобы не затереть параллельно создаваемый пакет иллюстраций.

## В составе v1.1.0

- «Сохранить черновик» не создаёт историческую запись.
- «Закончить тренировку» создаёт одну запись истории и подготавливает пустой черновик.
- Историческую тренировку можно открыть для доработки; сохраняется исходный ID записи.
- Во время доработки текущий черновик хранится отдельно и возвращается после сохранения или отмены.
- Контекст незавершённой доработки переживает перезапуск приложения.
- Убраны галочки выполнения подходов.
- Аналитика показывает только упражнения с реальными записями в истории.
- SQL-шаблон содержит исправление для `revision`; live-функция Supabase уже исправлена. Новая схема БД не требуется.

## Откат

Для возврата к визуальной версии до этой итерации сохранён `/mnt/data/SetLog_Checkpoint_v1.0.1_ui-fixes.zip`. Не очищать localStorage и не использовать восстановление старой облачной копии для отката интерфейса. При откате кода старые значения `done` безвредны: предыдущий код мог их использовать, а новая версия уже убирает их из нормализованного рабочего состояния.

## Границы проверки

Проверки сценариев v1.1.0 выполнены на тестовом наборе данных и изолированном браузерном окружении. Перед использованием на реальном аккаунте остаётся проверить опубликованный GitHub Pages, офлайн-кэш и онлайн-синхронизацию.
