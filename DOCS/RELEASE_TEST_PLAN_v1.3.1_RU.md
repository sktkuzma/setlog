# План проверки СЕТ v1.3.1

## Перед публикацией
1. Скачай резервную копию дневника из приложения.
2. Убедись, что базовый репозиторий соответствует архиву `setlog-main.zip` v1.3.0.
3. Загрузи файлы обновления в корень репозитория, включая папку `assets/anatomy/`.

## После публикации
1. Открой упражнение с мышечной группой «Грудь» — должна подсветиться грудная зона спереди.
2. Открой упражнение «Трицепс» — должна подсветиться задняя поверхность рук.
3. Проверь составную группу, например «Ягодичные / квадрицепс / приводящие»: подсвечиваются только имеющиеся маски квадрицепса и приводящих; для ягодичных отдельной маски пока нет.
4. Проверь «Икры»: подсветка должна быть на переднем и заднем видах.
5. Проверь упражнение с нераспознанной группой: карта остаётся нейтральной, приложение не должно показывать ошибку.
6. Проверь отображение карты на узком мобильном экране и после перехода между упражнениями.
7. Проверь работу после перезагрузки и в офлайн-режиме: ресурсы карты должны быть в `setlog-cache-v20`.
8. Сверь историю, текущий черновик, выбранную программу и пользовательские программы до/после обновления.

## Ограничения
- Маски являются визуальными и остаются на этапе проверки.
- Для ягодичных и разгибателей спины масок нет.
- Ручное подтверждение в реальном браузере/на телефоне всё равно требуется.
