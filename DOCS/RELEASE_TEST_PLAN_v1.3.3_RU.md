# Проверка релиза v1.3.3

1. Открыть экспорт, выбрать одну тренировку, сформировать PNG.
2. Проверить, что в PNG после сводных показателей есть блок «Анатомия / задействованные мышцы», силуэт и легенда.
3. Сформировать PNG за период и проверить общую карту по всем выбранным тренировкам.
4. Сформировать PDF для одной тренировки: должна быть отдельная страница анатомии.
5. Сформировать PDF за период: должна быть отдельная общая карта.
6. Проверить упражнения с группами без отдельной маски: они должны быть перечислены как неподсвеченные, без выдуманной подсветки.
7. Проверить онлайн и офлайн после активации нового Service Worker.
8. Убедиться, что история, программы и черновики на месте.

## Ограничение автоматической проверки
Синтаксис JavaScript, наличие ресурсов, архивы и контрольные суммы проверяются автоматически. Реальный рендер Canvas/PDF необходимо проверить в браузере после публикации.
