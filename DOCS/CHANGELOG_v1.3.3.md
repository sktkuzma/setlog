# SetLog v1.3.3 — анатомия в экспорте PNG и PDF

## Исправлено
- Анатомическая карта теперь включается в экспорт PNG.
- Для PNG карта строится из тех же сохранённых записей и масок, что и PDF.
- PNG-карточка увеличена по высоте, чтобы карта и легенда не перекрывали сводные показатели.
- Сохранена отдельная анатомическая страница PDF для одной тренировки и выбранного периода.
- Обновлён Service Worker cache до `setlog-cache-v22`.

## Данные
- Схема и ключ localStorage не менялись.
- История тренировок, программы, черновики и пользовательские упражнения не мигрируются и не перезаписываются.
