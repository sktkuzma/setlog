# Отчёт проверок СЕТ 1.1.0

## Результат

Изолированный Chromium smoke-test пройден. JavaScript-ошибок в консоли и необработанных исключений не зафиксировано.

Проверены сценарии:
- у строк подходов больше нет кнопок выполнения;
- «Сохранить черновик» сохраняет данные и не создаёт новую запись истории;
- селектор аналитики показывает только упражнения, для которых есть исторические записи;
- веса и повторы старой тренировки загружаются в режим доработки;
- изменения сохраняются в исходную запись, без создания дубликата;
- текущий черновик не затирается и возвращается после сохранения либо отмены;
- открытая доработка восстанавливается в новом экземпляре приложения по отдельному локальному ключу;
- «Закончить тренировку» создаёт одну запись и очищает рабочие значения для следующей сессии.

Тест выполнялся на изолированном наборе данных и с mock localStorage, без обращения к реальным аккаунтам. Он не заменяет проверку опубликованного GitHub Pages, Service Worker, реального Supabase и офлайн-синхронизации. Эти шаги перечислены в `RELEASE_TEST_PLAN_RU.md`.

## Данные и совместимость

- Версия схемы пользовательских данных остаётся v8; новая таблица Supabase не нужна.
- Старые отметки `done` в существующих локальных черновиках удаляются при нормализации и больше не отображаются.
- SQL-шаблон включает исправление неоднозначного `revision`, но повторное применение SQL к уже исправленной рабочей базе не требуется.
- В пакет обновления не включены иллюстрации/каталог, готовящиеся отдельно, чтобы случайно не перезаписать их.
