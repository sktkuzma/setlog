# СЕТ 1.0.0 — короткая проверка перед публикацией

Эта проверка нужна после загрузки обновления на GitHub Pages. На старом устройстве сначала скачай резервную копию из приложения.

## 1. Первая загрузка и миграция
1. Открой приложение с уже существующими данными и дождись загрузки.
2. Проверь, что программы и упражнения на месте, а приложение не просит создать дневник заново.
3. Открой упражнение, у которого в предыдущем черновике уже был указан вес: прежний вес должен появиться в строках подходов. Старые записи в «Истории» должны остаться видимыми.

## 2. Новая запись
1. Открой упражнение и введи разные значения, например: подход 1 — 60 кг × 10, подход 2 — 70 кг × 8, подход 3 — 70 кг × 7.
2. Отметь выполненным один из подходов, добавь ещё один подход и введи данные в него.
3. Нажми «Готово», вернись к списку, открой упражнение снова. Значения и отметки должны сохраниться.
4. Нажми «Сохранить тренировку», затем открой «История». Должны быть видны результаты по отдельным подходам.

## 3. Видео и редактор
1. Убедись, что Telegram открывает прежнюю ссылку, если она назначена.
2. Пока ссылка YouTube пустая, кнопка YouTube должна быть отключена.
3. В редакторе упражнения добавь тестовую ссылку формата `https://youtu.be/...`, сохрани, затем проверь, что кнопка активна. После теста удали тестовую ссылку, если она не относится к настоящему ролику.

## 4. Программы и настройки
1. Открой настройки через нижнее меню.
2. Выбери другую программу и вернись на главный экран.
3. Проверь, что открывается правильная программа и тренировочный день.
4. Проверь открытие библиотеки, редактора упражнения, резервной копии и окна аккаунта.

## 5. Офлайн и облако
1. После синхронизации включи авиарежим, измени одно значение подхода и дождись статуса локального сохранения.
2. Закрой и снова открой приложение без сети; изменение должно остаться.
3. Верни интернет, дождись автоматической синхронизации и проверь эту запись на втором аккаунте/устройстве, где входит тот же пользователь.
4. Не проверяй синхронизацию между разными аккаунтами путём передачи личного дневника: данные должны оставаться раздельными.

## Что считать блокером
- Программы или история исчезли после обновления.
- Изменения в весе/повторах пропадают после закрытия экрана.
- Тренировка сохраняется, но в истории нет результатов по подходам.
- Онлайн-правки не отправляются после возвращения сети.
