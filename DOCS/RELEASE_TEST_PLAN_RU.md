# Финальная проверка v1.0.1 перед дальнейшим редизайном

1. Сделать резервную копию дневника на телефоне.
2. Проверить единые отступы в «Настройках».
3. Проверить, что иллюстрации целиком видны в списке и карточке упражнения.
4. Убедиться, что карандашик в карточке — компактная квадратная кнопка.
5. Проверить SVG-логотипы Telegram и YouTube.
6. В редакторе упражнения добавить URL видео для варианта / замены. Сохранить, закрыть и вновь открыть карточку; нажать на название варианта и проверить адрес ссылки.
7. Проверить старую тренировку и историю на обоих аккаунтах.
8. При входе в аккаунт убедиться, что состояние дневника синхронизируется без конфликта.
9. Включить авиарежим, открыть приложение, затем вернуть интернет и убедиться в восстановлении синхронизации.
10. Если проверка успешна — продолжать работу с этой версией; исходную контрольную точку v1.0.0 хранить без изменений.
