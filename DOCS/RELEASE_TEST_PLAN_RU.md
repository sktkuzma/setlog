# План проверки релиза СЕТ 1.1.1

## Автоматические проверки, уже выполненные

- `node --check app.js` и `node --check sw.js`.
- Chromium regression suite v1.1.0: сохранение черновика, завершение тренировки, редактирование и отмена редактирования истории, восстановление после перезапуска, фильтр упражнений по истории.
- Переход по логотипу из настроек обратно на тренировку.
- Проверка, что введённый вес остаётся в черновике после перехода по логотипу.
- Проверка иконок: верхний и нижний SVG без transform-смещения, дополнительный glow отсутствует.
- Ошибок JS/console в прогоне не было.

## Проверить после публикации

1. Открой приложение на телефоне и настольном компьютере, обнови страницу.
2. Сравни верхнюю и нижнюю шестерёнки в активном и неактивном состояниях: вокруг не должно быть отдельного полупрозрачного кольца/свечения.
3. Внеси тестовое значение в подход, закрой карточку упражнения, перейди в «Настройки» или «История», затем нажми логотип «СЕТ». Убедись, что открылся экран тренировки и значение сохранилось.
4. Проверь, что страница не использует старые стили из кэша после обновления Service Worker.

Не требуется запускать SQL или выполнять миграцию данных.
