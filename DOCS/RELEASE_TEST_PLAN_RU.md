# План проверки релиза СЕТ 1.1.0

## Автоматические проверки, уже выполненные на изолированной копии

- Проверен синтаксис `app.js` и `sw.js`, уникальность HTML-ID и наличие всех ресурсов Service Worker.
- В Chromium проверено отсутствие галочек выполнения, разделение «Сохранить черновик» и «Закончить тренировку».
- Проверено, что сохранение черновика не создаёт историю, а завершение тренировки создаёт ровно одну запись и очищает текущие значения.
- Проверено, что селектор аналитики показывает только упражнения, встречающиеся в истории.
- Проверено заполнение исторической записи при доработке, сохранение изменений в исходную запись без дубликата, восстановление режима после перезапуска.
- Проверено сохранение и возврат текущего незаконченного черновика после сохранения или отмены доработки истории.
- В проверочном прогоне ошибок JavaScript в консоли не было. Использовались тестовые данные и локальный mock-хранилища; реальный Supabase/сеть не подменяли проверкой на продакшене.

## Короткий ручной smoke-test после публикации

1. Внести вес и повторения в 1–2 упражнениях и нажать **«Сохранить черновик»**. Обновить страницу: значения должны остаться, а запись в истории — не появиться.
2. Нажать **«Закончить тренировку»**. Должна появиться ровно одна запись истории, а рабочий экран должен подготовить пустой черновик.
3. Начать новую тренировку, заполнить пару подходов, затем открыть предыдущую тренировку в истории и нажать **«Доработать тренировку»**.
4. Изменить вес/повторы и перезагрузить приложение: режим редактирования должен восстановиться.
5. Нажать **«Сохранить изменения»**. Должна обновиться исходная запись истории без дубликата; незавершённая новая тренировка должна вернуться с прежними значениями.
6. Проверь отмену доработки: старая запись остаётся без изменений, текущий черновик возвращается.
7. В селекторе аналитики убедиться, что доступны только упражнения с записями в истории.
8. Войти в облачный аккаунт и проверить статус синхронизации; затем проверить восстановление сети после офлайна.

## Важно

Пакет обновления не содержит иллюстраций SVG/JPG/PNG или каталога упражнений: он не перезапишет новые изображения, которые готовятся отдельно. Схема Supabase для этой версии не меняется. `supabase-setup.sql` включает исправленную конструкцию для сохранения копий; рабочая функция в Supabase уже исправлена, запуск SQL не требуется.
