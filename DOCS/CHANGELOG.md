# История изменений СЕТ

## v1.1.0

- Разделены сохранение незавершённого черновика и окончание тренировки.
- Добавлена доработка исторической тренировки с сохранением исходной записи до явного сохранения.
- Текущий черновик не изменяется при переходе в историю и возвращается после сохранения либо отмены доработки.
- Черновик доработки сохраняется локально и восстанавливается после закрытия приложения.
- Убраны галочки выполнения подходов.
- В аналитике список упражнений строится только по фактическим записям истории.
- Обновлён кэш Service Worker до v16. Новые иллюстрации по тем же путям можно добавить отдельным пакетом.
- Схема данных Supabase не менялась. Исправленная версия `supabase-setup.sql` включает указание уникального ограничения вместо неоднозначной ссылки на `revision`; live-функция уже исправлена.

## v1.0.1 — визуальные исправления

- Выровнены вертикальные интервалы в разделе настроек и карточках программ.
- Изображения упражнений показываются в пределах контейнера без дополнительного обрезания.
- Кнопка редактирования упражнения получила фиксированный компактный размер.
- На кнопках Telegram и YouTube используются SVG-логотипы.
- «Вариант / замена» поддерживает ссылки на видео.
- Библиотека и её внутренние идентификаторы переименованы в Coach; старые сохранённые идентификаторы преобразуются при загрузке.
- Кэш Service Worker обновлён до v15.

## v1.0.0 — редизайн и подходы

- Тёмный интерфейс с салатовым акцентом.
- Вес и повторения хранятся отдельно для каждой строки подхода.
- Миграция старого веса в новый формат и история результатов по подходам.
