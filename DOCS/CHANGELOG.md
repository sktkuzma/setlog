# SetLog v1.3.3 — анатомия в экспорте PNG и PDF

## Исправлено
- Анатомическая карта теперь включается в экспорт PNG.
- Для PNG карта строится из тех же сохранённых записей и масок, что и PDF.
- PNG-карточка увеличена по высоте, чтобы карта и легенда не перекрывали сводные показатели.
- Сохранена отдельная анатомическая страница PDF для одной тренировки и выбранного периода.
- Обновлён Service Worker cache до `setlog-cache-v22`.

## Данные
- Схема и ключ localStorage не менялись.
- История тренировок, программы, черновики и пользовательские упражнения не мигрируются и не перезаписываются.

# СЕТ — журнал изменений

- Версия приложения: 1.3.1.
- Схема данных остаётся версии 8. Ключи localStorage, история, черновики и программы не изменялись.
- Маски остаются визуальными материалами на этапе проверки, не медицинской сегментацией.

## v1.3.2 — Исправление анатомии в PDF (2026-10-30)

- Добавлена отдельная страница «Карта задействованных мышц» в PDF отчёт за одну тренировку и за период.
- Карта формируется из той же нейтральной основы и PNG-масок, что используются в карточке упражнения.
- Для периодного отчёта объединяются мышечные группы всех тренировок выбранного периода.
- Группы, для которых пока нет маски, перечисляются отдельно, без ложной подсветки.
- PDF-экспорт теперь ожидает загрузки анатомических изображений до сборки PDF.
- Повышена версия Service Worker cache до v21, чтобы браузер забрал исправленный app.js.
- Данные тренировок, localStorage и схема хранения не менялись.
