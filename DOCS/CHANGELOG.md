# СЕТ — журнал изменений

## 1.3.1 — 30 октября 2026

- Добавлена анатомическая карта в карточку упражнения: нейтральная основа и отдельные полупрозрачные маски мышечных групп.
- Подсветка выбирается по тексту поля «Мышечная группа»; поддерживаются составные группы через `/`.
- Для упражнений без соответствующей маски показывается нейтральная карта и пояснение.
- Добавлены 14 PNG-масок, manifest и ресурсы анатомии в `assets/anatomy/`.
- Service Worker обновлён до `setlog-cache-v20` и включает все файлы анатомической карты.
- Версия приложения: 1.3.1.
- Схема данных остаётся версии 8. Ключи localStorage, история, черновики и программы не изменялись.
- Маски остаются визуальными материалами на этапе проверки, не медицинской сегментацией.

# Журнал изменений СЕТ

## 1.2.0 — 29 октября 2026

- Дополнен сценарий «Забыли пароль?»: письмо отправляется через Supabase Auth с возвратом на URL проекта GitHub Pages.
- Добавлено состояние установки нового пароля с подтверждением совпадения и проверкой минимальной длины.
- Добавлена кнопка возврата из recovery-режима, которая завершает временную recovery-сессию.
- Ответ на запрос сброса пароля не раскрывает, существует ли аккаунт с введённым email.
- Добавлен экран «Поделиться результатами» в разделах «История» и «Прогресс».
- Экспорт PNG и многостраничный PDF строятся локально в браузере.
- Доступны период дат, целая историческая тренировка и отбор отдельных упражнений с реально сохранёнными результатами.
- Исправлен расчёт дат в локальном часовом поясе.
- Добавлен предохранитель для очень длинных отчётов (лимит высоты 16 000 px), чтобы не перегружать память мобильного браузера.
- Service Worker обновлён до `setlog-cache-v18`.
- Схема данных остаётся версии 8; Supabase SQL и таблицы не менялись.
