# История изменений СЕТ

## v1.0.1 — визуальные исправления
- Выровнены вертикальные интервалы в разделе настроек и карточках программ.
- Изображения упражнений показываются в пределах контейнера без дополнительного обрезания; главный рисунок получил более подходящие пропорции.
- Кнопка редактирования упражнения получила фиксированный компактный размер.
- На кнопках Telegram и YouTube используются SVG-логотипы.
- Строка «Вариант / замена» поддерживает ссылки на видео: ссылка задаётся в редакторе; также приложение пытается найти совпадающее название в библиотеке.
- Библиотека и её внутренние идентификаторы переименованы в Coach. При чтении старых локальных/облачных данных старые идентификаторы преобразуются согласованно, чтобы сохранить связи с историей.
- Кэш Service Worker обновлён до v15.

## v1.0.0 — редизайн и подходы
- Тёмный интерфейс с салатовым акцентом.
- Вес, повторения и отметка выполнения хранятся в каждой строке подхода.
- Миграция старого веса в новый формат и история результатов по подходам.
