# СЕТ 1.0.0 — изменения

Дата сборки: 28 октября 2026 года.

## Интерфейс
- Переработан мобильный интерфейс в тёмной палитре с салатовым акцентом.
- Главный экран показывает программу, тренировочный день и компактные карточки упражнений.
- В карточке упражнения открывается подробный экран с иллюстрацией, группой мышц, планом, заменой, заметкой и предыдущим результатом.
- Добавлены отдельные кнопки видео для Telegram и YouTube. YouTube-кнопка остаётся неактивной, пока в редактор упражнения не добавлена корректная ссылка.
- Добавлен отдельный экран настроек с программами, библиотекой, синхронизацией, установкой PWA и резервными копиями.

## Запись подходов
- У каждого подхода свои поля веса и повторений.
- Можно отмечать подходы выполненными, добавлять и удалять строки; максимум 20 строк на упражнение.
- Новая история тренировки включает `setResults` с весом, повторениями и статусом каждого записанного подхода. Для совместимости также заполняются агрегированные поля старого формата.
- История старых тренировок не переписывается: интерфейс продолжает показывать старый формат и новые подробные результаты. В новых записях число подходов считается по заполненным строкам; пустые добавленные строки не попадают в историю.

## Совместимость и сохранность
- Версия схемы локальных данных повышена с 6 до 7.
- При миграции общий вес из прежнего черновика переносится в строки подходов, а исходная версия данных сохраняется в резервной копии перед завершением миграции.
- Существующие аккаунты и таблицы Supabase не требуют изменения SQL-схемы для этой версии.
- Обновлён кеш service worker до `setlog-cache-v14`.

## Проверки
- Синтаксис `app.js` и `sw.js` проверен Node.js.
- HTML: уникальность ID и наличие элементов, к которым обращается код, проверены статически.
- Локальные PWA-ресурсы и библиотека упражнений проверены на существование/валидность.
- Изолированный UI smoke-test в системном Chromium прошёл: миграция v6, независимые значения подходов, добавление подхода, история, YouTube-ссылка и экран настроек. Ошибок страницы и консоли не было.
- Работа на опубликованном домене, Service Worker, живой Supabase-синхронизации и реальное отключение/восстановление сети требуют короткой проверки после загрузки.
