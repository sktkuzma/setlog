## Проверенные сценарии сопоставления

Проверены грудь, плечи/дельты, бицепс, трицепс, предплечья, пресс, квадрицепс, бицепс бедра, икры, широчайшие, верх спины, составные мышечные группы, ягодицы и разгибатели спины.

Для ягодиц и разгибателей спины отдельные маски не создаются; карта остаётся без ложной подсветки этих групп.

## Ограничения проверки

Автоматизированный браузерный сценарий в текущей среде блокируется политикой браузера (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому реальный рендер интерфейса, офлайн-режим и отображение на телефоне требуют ручной проверки после публикации.
