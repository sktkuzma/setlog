СЕТ 1.1.1 — исправление значков и перехода на главную тренировку

Что исправлено:
- Убрано смещение контура верхней шестерёнки.
- Удалено дополнительное свечение вокруг нижнего значка настроек.
- Логотип «СЕТ» в верхней панели возвращает к экрану тренировки из любой вкладки.
- Содержимое черновика при переходе по логотипу сохраняется.
- Service Worker обновлён до setlog-cache-v17, чтобы клиенты получили новые стили.

Публикация:
1. Скачай резервную копию дневника.
2. Распакуй архив SetLog_Update_v1.1.1.zip.
3. Загрузи файлы из корня архива в корень GitHub-репозитория, заменяя одноимённые.
4. Закоммить изменения в main и проверь сайт на телефоне.

В ZIP нет изображений и каталога упражнений: пакет будущих иллюстраций не затрагивается. SQL и Supabase не менялись.
