СЕТ v1.3.0 — визуальный экспорт статистики

1. Перед обновлением скачай резервную копию дневника в приложении.
2. Убедись, что в main уже опубликована совместимая база v1.2.0 (в ней есть восстановление пароля и первый диалог экспорта).
3. Распакуй этот архив обновления и загрузи файлы из его корня в корень репозитория GitHub Pages с заменой одноимённых файлов.
4. Сделай коммит в main и дождись публикации.

PNG — компактная карточка 4:5: отдельный вариант для одной тренировки и сводка за период/выбранные упражнения. PDF — многостраничный отчёт со сводкой, отдельными графиками рабочих весов, рейтингом прироста, суммой повторений и журналом либо подробностями одной тренировки.

Экспорт использует только сохранённую историю. Время нахождения в зале и калории не добавляются — приложение не собирает эти данные. Объём учитывает только подходы с весом и повторениями. График прироста строится только если у одного упражнения есть минимум две пригодные записи.

Файлы создаются локально в браузере. Архив обновления намеренно не содержит иллюстрации, каталог упражнений, supabase-config.js и SQL, поэтому не перезаписывает параллельно готовящиеся изображения. Схема Supabase не менялась, SQL запускать не нужно.
