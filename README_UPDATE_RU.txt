СЕТ 1.0.1 — точечные исправления мобильного интерфейса

Что изменилось:
- выровнены вертикальные интервалы в настройках;
- карточки изображений упражнений показывают картинку целиком, пропорции главного изображения стали удобнее;
- кнопка карандаша в списке упражнений фиксированная и компактная;
- добавлены SVG-логотипы Telegram и YouTube;
- строка «Вариант / замена» становится ссылкой на видео, если приложение находит совпадающее упражнение в библиотеке; для любого другого варианта можно указать отдельный URL в редакторе упражнения;
- файлы и идентификаторы библиотеки переименованы в Coach; старые сохранённые локальные/облачные данные автоматически приводятся к новым идентификаторам, чтобы сохранить связь программ, черновиков и истории;
- обновлён кэш Service Worker до setlog-cache-v15.

Как опубликовать:
1. До обновления скачай резервную копию дневника из приложения.
2. Распакуй архив обновления и загрузи все файлы из корня архива в корень репозитория GitHub с заменой одноимённых файлов. Важно: добавь новый файл exercise-library-coach.json и не оставляй старую версию приложения ссылаться на старое имя библиотеки.
3. Сделай коммит в main. SQL Supabase для этой версии не изменялся, повторный запуск не требуется.
4. После публикации проверь, что обе программы и история остались на месте, а ссылки Telegram/YouTube открываются. Для варианта/замены при необходимости добавь видео в редакторе упражнения.

Архив подготовлен для загрузки и не опубликован автоматически. Подробный отчёт и список проверок лежат в DOCS.
