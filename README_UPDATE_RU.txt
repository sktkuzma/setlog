СЕТ 1.0.0 — редизайн и запись по подходам

Что изменилось:
- новый тёмный интерфейс с салатовым акцентом;
- подробный экран упражнения с иллюстрацией, мышечной группой, планом, заменой и заметками;
- отдельные поля веса и повторений для каждого подхода;
- отметка выполнения, добавление/удаление строк (до 20 подходов на упражнение);
- две кнопки видео: Telegram и YouTube; YouTube пока неактивен до добавления ссылки в редакторе;
- нижняя навигация для тренировки, прогресса, истории и настроек;
- настройки программ, библиотеки, аккаунта и резервных копий собраны на отдельном экране;
- миграция schema v6 → v7 переносит старый общий вес в строки подходов; история сохраняется;
- обновлён кеш PWA до setlog-cache-v14.

Загрузка обновления:
1. Скачай резервную копию из приложения и сохрани исходники текущей опубликованной версии.
2. Распакуй архив обновления и загрузи все файлы из его корня в корень репозитория GitHub, заменяя одноимённые файлы.
3. Сделай коммит в main. SQL Supabase повторно запускать не нужно.
4. После публикации пройди короткую проверку из DOCS/RELEASE_TEST_PLAN_RU.md.

В архиве есть DOCS/TEST_REPORT.md: статические проверки и изолированный UI smoke-test в Chromium пройдены. На опубликованном сайте ещё нужно проверить фактическое обновление, работу Service Worker, реальную офлайн-синхронизацию и облако Supabase. Приложение не было опубликовано этим процессом — архив подготовлен для загрузки.
