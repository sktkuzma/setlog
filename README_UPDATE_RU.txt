СЕТ — обновление v0.8.0: библиотека из 201 упражнения

ПЕРЕД ЗАГРУЗКОЙ: открой СЕТ на телефоне → История → Экспорт JSON и сохрани файл отдельно.

1. Распакуй архив.
2. В существующем GitHub-репозитории выбери Add file → Upload files.
3. Загрузи все файлы приложения из архива в корень репозитория (на один уровень с index.html), замени совпадающие имена. ZIP как файл не загружай.
4. Выполни Commit changes в main и дождись публикации Pages.
5. Открой сайт на телефоне с интернетом; не очищай данные браузера и не удаляй ярлык/приложение.
6. Проверь обе программы, историю, библиотеку, фильтр мышечных групп, добавление упражнения и экспорт JSON. Только после ручной проверки создай Release v0.8.0-exercise-library.

Что нового: JSON-каталог из 201 уникального упражнения, у всех есть ссылка на Telegram; поиск по названию и синонимам; фильтр по мышечной группе; стабильные ID внешних упражнений; каталог хранится в файлах сайта и копируется в пользовательские данные только после добавления упражнения в программу; schema v5; cache v9.

Данные по-прежнему хранятся на устройстве в браузере; облачной синхронизации нет. Сохраняй внешний JSON-экспорт.
