СЕТ 1.2.0 — восстановление пароля и экспорт результатов

Что добавлено:
- «Забыли пароль?» отправляет письмо восстановления на указанную почту.
- Ссылка из письма возвращает пользователя в СЕТ для задания нового пароля; два поля проверяются на совпадение.
- Экспорт сохранённой истории в красивый PNG или многостраничный PDF.
- Источники экспорта: диапазон дат, одна тренировка целиком или выбранные упражнения с результатами в истории.
- Файлы формируются на устройстве, история не передаётся внешнему сервису рендеринга.
- Локальная дата для диапазонов считается в часовом поясе устройства.

Перед публикацией:
1. Скачай резервную копию дневника.
2. Распакуй SetLog_Update_v1.2.0.zip.
3. Загрузи файлы из корня архива в корень репозитория, с заменой одноимённых файлов. Не трогай иллюстрации и каталог упражнений.
4. Обнови файлы в DOCS, если хочешь хранить документацию релиза в репозитории.
5. Сделай коммит в main и дождись GitHub Pages.

Supabase:
- SQL и схема базы не менялись, ничего повторно запускать не нужно.
- Проверь в Supabase → Authentication → URL Configuration, что Redirect URLs включает https://sktkuzma.github.io/setlog/.
- После публикации обязательно запроси письмо восстановления на тестовом аккаунте и пройди весь цикл. Фактическая доставка письма из среды разработки не проверялась.

Экспорт нужно проверить после публикации: PNG должен открываться как изображение, PDF — как документ с несколькими страницами для длинных периодов. В тестовой среде отдельно проверена структура PDF 1.4/A4; браузерный end-to-end тест UI и реальная почтовая доставка здесь не выполнены.
