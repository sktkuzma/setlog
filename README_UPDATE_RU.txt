СЕТ 1.1.0 — черновик тренировки и редактирование истории

Что изменилось:
- «Сохранить черновик» сохраняет текущие значения и не создаёт запись в истории.
- «Закончить тренировку» добавляет одну историческую запись и очищает рабочий черновик для следующей сессии.
- Добавлена «Доработать тренировку» в карточку истории: веса, повторения и заметки загружаются в тот же редактор, а сохраняются обратно в исходную запись без дубликата.
- Незавершённый черновик до начала доработки истории защищён отдельно и возвращается после сохранения либо отмены доработки. Контекст доработки переживает перезапуск приложения.
- Убраны отметки выполнения подходов.
- В селекторе аналитики остаются только упражнения с реальными записями в истории.
- Обновлён Service Worker до setlog-cache-v16.
- Пакет не содержит иллюстраций и каталога упражнений, чтобы не перезаписать файлы, готовящиеся отдельно. `SHA256SUMS.txt` содержит хеши исходников и документов, но не изображений/каталога.
- В `supabase-setup.sql` включено исправление неоднозначного `ON CONFLICT` для `revision`. В рабочей базе Supabase исправление уже применено; повторно запускать SQL не надо.

Как опубликовать:
1. До обновления скачай резервную копию дневника.
2. Распакуй архив обновления и загрузить файлы из корня архива в корень репозитория GitHub с заменой одноимённых файлов. Архив содержит только обновлённые исходники и документы; новые картинки не трогает.
3. Сделай коммит в `main` и дождись публикации GitHub Pages.
4. Проверь по `DOCS/RELEASE_TEST_PLAN_RU.md` сохранение черновика, завершение тренировки, доработку/отмену записи истории и фильтр аналитики. Онлайн-синхронизацию проверь на опубликованном сайте.

Архив подготовлен для загрузки и не опубликован автоматически.
