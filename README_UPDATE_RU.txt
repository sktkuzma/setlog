СЕТ v1.3.1 — анатомическая карта

1. Перед обновлением скачай резервную копию дневника из раздела «Настройки».
2. Сохрани текущую версию репозитория или используй контрольную точку v1.3.0.
3. Загрузи содержимое архива обновления в корень репозитория GitHub с заменой одноимённых runtime-файлов и добавлением папки assets/.
4. Сделай коммит в main и дождись публикации GitHub Pages.
5. Открой приложение, обнови страницу. Если карта не появилась сразу, закрой установленное PWA и открой повторно после обновления Service Worker.

В карточке упражнения между ссылками на видео и информационными параметрами появится карта задействованных мышц. Она строится по полю «Мышечная группа». Если в названии группы перечислено несколько целей через '/', будут подсвечены все доступные для них маски.

Данные:
- ключ localStorage `setlog-pwa-v1` не меняется;
- DATA_SCHEMA_VERSION остаётся 8;
- миграции истории и программ не выполняются;
- Supabase, конфигурация и SQL не меняются.

Ограничение: ягодичные и разгибатели спины не имеют отдельных масок в текущем комплекте. Маски — визуальная подсказка на этапе проверки.
