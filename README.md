# СЕТ — дневник тренировок 1.2.0

Релиз добавляет полноценный пользовательский сценарий восстановления пароля и экспорт результатов тренировок в PNG/PDF. Данные дневника остаются в локальном хранилище и синхронизируются с Supabase по прежним правилам.

## Новое в 1.2.0

- Восстановление пароля: запрос письма по email, переход по ссылке обратно в СЕТ, повторный ввод нового пароля и подтверждение совпадения.
- Для запросов сброса показывается нейтральный ответ: приложение не сообщает, существует ли аккаунт с указанным адресом.
- Возврат из режима восстановления завершает временную recovery-сессию и показывает экран входа.
- Экспорт результатов в виде аккуратного PNG или многостраничного PDF формируется на устройстве; история не отправляется внешнему сервису для создания отчёта.
- Экспорт можно сформировать за выбранный период, по одной сохранённой тренировке целиком или по выбранным упражнениям. В списке упражнений отображаются только упражнения, по которым есть исторические записи.
- В быстрых диапазонах дат исправлен расчёт локальной даты для часовых поясов.
- Для защиты памяти мобильного браузера отчёты выше 16 000 px не строятся, приложение предлагает уменьшить период или число упражнений.
- Обновлён Service Worker до `setlog-cache-v18`.

## Сохранность данных и совместимость

- Схема пользовательских данных остаётся версии 8. Миграция базы данных и запуск SQL не требуются.
- `supabase-config.js`, `supabase-setup.sql`, иллюстрации и каталог упражнений в этом релизе не меняются.
- Экспортные файлы собираются в браузере; приложение не загружает историю в сервис рендеринга.
- Перед обновлением рекомендуется скачать отдельную резервную копию дневника.

## Восстановление пароля: требование Supabase

В Supabase → Authentication → URL Configuration должен быть разрешён redirect URL `https://sktkuzma.github.io/setlog/`. Если он не внесён в Redirect URLs, Supabase не позволит направить письмо восстановления обратно в приложение. Сама отправка письма также зависит от настроенной почтовой доставки Supabase.

## Установка обновления

Распакуйте `SetLog_Update_v1.2.0.zip` и загрузите файлы из корня архива в корень репозитория `sktkuzma/setlog`, заменив одноимённые файлы. Обновите также файлы в папке `DOCS`, если хотите сохранить документацию релиза в GitHub. Закоммитьте изменения в `main` и дождитесь публикации GitHub Pages.

Архив обновления не содержит иллюстраций и каталога упражнений — новые изображения из параллельной работы не будут перезаписаны. Не загружайте полный архив восстановления поверх репозитория: он предназначен для локального отката.


## Анатомическая карта (v1.3.1)

В карточке упражнения отображается схема мышц по полю «Мышечная группа». Ресурсы находятся в `assets/anatomy/`; manifest содержит стабильные ID масок. Маски — визуальные материалы на этапе проверки, не медицинская сегментация. Для ягодичных, разгибателей спины и некоторых небольших групп отдельных масок пока нет.
