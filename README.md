# СЕТ — дневник тренировок

**СЕТ** — веб-приложение для планирования силовых тренировок, записи подходов и отслеживания прогресса. Работает на телефоне и компьютере через браузер. На поддерживаемых устройствах его можно установить на домашний экран как PWA.

## Возможности

- **Программы тренировок:** готовые Full Body и Girls, создание собственных программ и тренировочных дней, настройка порядка упражнений.
- **Библиотека упражнений:** поиск, добавление и замена упражнений, редактирование пользовательских вариантов.
- **Дневник:** вес и повторения для каждого подхода, черновики, история тренировок и редактирование ранее сохранённых записей.
- **Анализ прогресса:** динамика рабочих весов, личные рекорды и распределение нагрузки по группам мышц.
- **Отчёты:** экспорт PNG и многостраничных PDF для отдельной тренировки или выбранного периода.
- **Учётная запись:** облачная синхронизация через Supabase с возможностью работы локально.

Иллюстрации упражнений помогают ориентироваться в библиотеке и не заменяют профессиональную консультацию по технике и состоянию здоровья.

## Как начать

1. Откройте [приложение](https://sktkuzma.github.io/setlog/).
2. Выберите готовую программу или создайте свою.
3. Запишите вес и повторения в выполненных подходах.
4. Сохраните тренировку, чтобы она появилась в истории.
5. При желании создайте учётную запись для доступа к облачной синхронизации.

Установка на домашний экран доступна через меню совместимого браузера. Для просмотра и ведения локального дневника регистрация не обязательна.

## Сохранность данных

СЕТ хранит локальную копию дневника в браузере. Для авторизованных пользователей предусмотрена синхронизация с облаком при наличии подключения к интернету. Дневники разных аккаунтов разделены.

**Рекомендуется регулярно экспортировать резервную копию дневника в JSON через настройки**, особенно перед очисткой данных браузера, сменой устройства и импортом другого файла. Исходники в GitHub и ZIP-архивы приложения **не содержат пользовательскую историю тренировок** и не восстанавливают её автоматически.

Если приложение обнаружило изменение дневника в другой вкладке, продолжение сохранения в устаревшей вкладке блокируется. Обновите её перед дальнейшей работой. Не рекомендуется параллельно изменять один дневник офлайн на нескольких устройствах.

При восстановлении из JSON проверьте выбранную копию и сначала экспортируйте текущее состояние: импорт может заменить данные дневника.

## Обновления и версии

Номер **последнего опубликованного релиза** отображается автоматически на значке в начале страницы. В исходном коде версия хранится в [`VERSION.txt`](VERSION.txt). Автоматические проверки сверяют номер версии, заголовок приложения и наличие соответствующего списка изменений, чтобы сведения не расходились.

Проверенные выпуски публикуются в [GitHub Releases](https://github.com/sktkuzma/setlog/releases). Для каждого выпуска предусмотрены:

- **Update-only ZIP** — файлы обновления приложения.
- **Full-restore ZIP** — полный снимок исходников и ресурсов соответствующей версии для восстановления сайта.

Обычное обновление опубликованного приложения не предполагает очистки дневников. Тем не менее перед существенными изменениями рекомендуется сохранять резервную копию JSON. Архив восстановления сайта не заменяет пользовательский экспорт данных.

## Разработка

Проект использует HTML, CSS и JavaScript. Для локального запуска нужен статический HTTP-сервер. В GitHub Actions работают проверки синтаксиса, версии, сценариев сохранения и регрессий. Наличие пройденных тестов не гарантирует одинаковое поведение во всех браузерах и на всех устройствах.

Для предложений и сообщений об ошибках используйте [GitHub Issues](https://github.com/sktkuzma/setlog/issues). Укажите браузер, шаги воспроизведения и ожидаемый результат. Не публикуйте пароли, токены доступа, личные данные или содержимое дневника.
