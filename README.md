# СЕТ — дневник тренировок (PWA)

Мобильный дневник с тремя тренировочными днями, учётом подходов, истории, графиками прогресса, добавлением упражнений и резервным копированием в JSON.

## Публикация через GitHub Pages

1. Создай на GitHub новый **Public**-репозиторий, например `setlog`.
2. Распакуй архив и загрузи **содержимое этой папки** в корень репозитория (файлы `index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, иконки, `.nojekyll` и этот README). Сам ZIP-файл загружать не нужно.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/(root)`, нажми **Save**.
5. Дождись публикации и открой адрес вида `https://USERNAME.github.io/setlog/`.
6. На телефоне открой тот же адрес и выбери установку/добавление на главный экран.

## Как публиковать дальнейшие правки

Загружай изменённые файлы в те же пути репозитория и фиксируй (**Commit changes**) в ветку `main`. GitHub Pages автоматически опубликует обновление. Открытая в данный момент вкладка обновится после перезагрузки; сервис-воркер использует сеть при подключении и кэш как резерв для офлайн-режима.

## Локальные данные

Журнал хранится в `localStorage` браузера на конкретном устройстве. Репозиторий и сайт не синхронизируют записи между устройствами. Периодически экспортируй JSON через экран «История» и сохрани файл отдельно. При смене телефона импортируй резервную копию.
