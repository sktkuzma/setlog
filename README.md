# СЕТ — дневник тренировок

**Версия:** 0.9.1 — облачная конфигурация подключена.  
**Схема личных данных:** v6.  
**PWA cache:** v11.  
**Supabase project:** `setlog` (`xikwzwqorwdhwhurzmlx`, `eu-north-1`).

СЕТ — статическое PWA на GitHub Pages. Проект Supabase создан, таблица пользовательского состояния и RLS-политики применены, функция сохранения проверяет ожидаемую ревизию. Публичный publishable key находится в `supabase-config.js`; это ожидаемо для клиентского приложения. Секретные ключи в пакет не включались.

## Что в v0.9.1

- Настроен клиентский URL и publishable key созданного проекта.
- Схема в `supabase-setup.sql` синхронизирована с реально применённой версией: RLS на таблице, ограничения по `auth.uid()`, `SECURITY INVOKER`, ограничение размера payload и проверка ревизии.
- Обновлена документация по Auth URL Configuration и ограничениям встроенного SMTP.
- PWA cache повышен до v11, чтобы браузер подтянул обновлённую конфигурацию.
- Реализованные в v0.9.0 функции сохранены: аккаунт по email/паролю, восстановление пароля, облачная синхронизация, миграция локальных данных и выбор замены упражнения из общей библиотеки с сохранением исходной истории.

## Перед публикацией

1. Экспортируй историю в JSON с телефона.
2. Открой [Auth → URL Configuration](https://supabase.com/dashboard/project/xikwzwqorwdhwhurzmlx/auth/url-configuration), задай Site URL `https://sktkuzma.github.io/setlog/` и добавь тот же URL в Redirect URLs.
3. Проверь Email provider. Встроенный SMTP Supabase по умолчанию отправляет письма только на адреса участников команды проекта; для регистрации друзей с подтверждением email нужен отдельный SMTP-провайдер.
4. Загрузи все файлы из корня архива в корень `sktkuzma/setlog`, одним коммитом в `main`.
5. После публикации протестируй регистрацию, подтверждение email, вход, восстановление пароля, перенос данных, синхронизацию и замену упражнения.

Подробные шаги — в `SUPABASE_SETUP_RU.md`.

## Ограничения

- Supabase Auth и реальная синхронизация станут доступны пользователям после публикации и настройки Redirect URLs.
- Встроенная почта Supabase ограничена тестовым использованием; для друзей нужен SMTP-провайдер.
- Локальная история ещё не загружена автоматически: при первом входе нужно подтвердить источник данных и выполнить импорт, если на устройстве есть записи.
- Supabase Free не заменяет внешние резервные копии. Сохраняй JSON отдельно.
