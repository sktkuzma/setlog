# СЕТ — дневник тренировок 1.0.0

Мобильный PWA-дневник тренировок с локальным сохранением и синхронизацией Supabase после входа в аккаунт.

## Что нового в 1.0.0
- Переработан тёмный мобильный интерфейс с салатовым акцентом.
- Вес и повторения записываются отдельно для каждого подхода.
- Добавлены отметки выполненных подходов и добавление строк.
- Добавлена будущая YouTube-ссылка рядом с существующим Telegram-видео.
- Добавлен экран настроек.
- Данные schema v6 автоматически мигрируют на schema v7, старые результаты истории сохраняются.

## Обновление GitHub Pages
1. Скачай резервную копию данных из приложения.
2. Распакуй `SetLog_Update_Redesign_v1.0.0.zip` и загрузи файлы из корня архива в корень репозитория, заменяя одноимённые.
3. Сделай commit в ветку `main` и дождись публикации GitHub Pages.
4. Проверь основные сценарии из `DOCS/RELEASE_TEST_PLAN_RU.md`. Интерфейс и базовые сценарии уже прошли изолированный UI smoke-test, но облако и Service Worker нужно проверить на опубликованном сайте.

SQL повторно выполнять не нужно. Перед публикацией стоит сохранить исходники версии 0.9.2 и отдельную резервную копию данных из приложения.
