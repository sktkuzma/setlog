# СЕТ — дневник тренировок 1.1.1

Патч интерфейса для v1.1.0: исправлены значки настроек и переход на тренировку по логотипу.

## Что изменено в 1.1.1

- Верхняя и нижняя шестерёнки используют один центрированный SVG без смещения контура.
- Убрано дополнительное свечение `drop-shadow` у значка настроек в нижней навигации.
- Нажатие на логотип «СЕТ» в верхней панели возвращает к экрану тренировки.
- Переход не очищает текущий черновик; проверено в Chromium.
- Service Worker обновлён до `setlog-cache-v17`, чтобы браузеры забрали исправленные HTML/CSS.

Это небольшой патч к 1.1.0. Он не включает иллюстрации или каталог упражнений и не меняет структуру данных или Supabase.

## Установка

Сделайте резервную копию дневника. Распакуйте `SetLog_Update_v1.1.1.zip` и загрузите файлы из корня архива в корень репозитория `sktkuzma/setlog`, заменив одноимённые файлы. В архиве намеренно нет файлов иллюстраций и каталога. Закоммитьте в `main`.

Не загружайте архив контрольной точки целиком в репозиторий: он предназначен для отката локальной версии.
