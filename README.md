# СЕТ — дневник тренировок 1.0.1

Мобильное PWA-приложение для записи тренировок. Данные сохраняются на устройстве, а после входа в аккаунт синхронизируются с Supabase.

## Что исправлено в 1.0.1
- Выровнены вертикальные отступы в разделе настроек.
- Исправлена подача изображений: изображения укладываются целиком в рамку, а основной кадр получил более подходящие пропорции.
- Кнопка редактирования упражнения стала компактной и фиксированной по размеру.
- В кнопках видео используются SVG-логотипы Telegram и YouTube.
- «Вариант / замена» может вести на видео: приложение пытается найти соответствие по названию в библиотеке, а отдельную ссылку можно задать в редакторе упражнения.
- Библиотека и её ID переименованы в Coach. При загрузке старых данных локальные и облачные идентификаторы преобразуются согласованно, поэтому ссылки из программ и истории сохраняются.
- Версия схемы данных — 8; предыдущие поля и история сохраняются. Обновлён кэш Service Worker до v15.

## Как обновить GitHub Pages
1. Перед обновлением скачай резервную копию дневника из приложения.
2. Распакуй `SetLog_Update_Redesign_v1.0.1.zip` и загрузи все файлы из корня архива в корень репозитория, заменяя одноимённые. Добавь новый `exercise-library-coach.json`.
3. Сделай коммит в `main` и дождись публикации GitHub Pages.
4. Пройди `DOCS/RELEASE_TEST_PLAN_RU.md`; облако и реальный офлайн-режим нужно проверять на опубликованном сайте.

SQL Supabase для этого релиза не менялся. Релизный архив подготовлен для загрузки и не опубликован автоматически. Контрольная точка предыдущей версии должна храниться отдельно и не перезаписываться.
