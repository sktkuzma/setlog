# СЕТ — дневник тренировок (PWA)

**Версия:** 0.8.0 — библиотека упражнений.
**Схема личных данных:** v5.

СЕТ — мобильный дневник тренировок, публикуемый статическим сайтом через GitHub Pages. Программы Full Body и «Девушки — 2 раза в неделю» остаются пользовательскими; новая библиотека дополняет редактор упражнений.

## Библиотека упражнений

- Подключён каталог `exercise-library-tulupavel.json`: 201 упражнение, 15 категорий мышечных групп, 201 ссылка на сообщения Telegram.
- В приложении можно искать по названию и синонимам, фильтровать по мышечной группе и добавлять упражнение в выбранный тренировочный день.
- Новые упражнения имеют стабильные ID вида `tulupavel-130`; данные о происхождении и ссылка на технику сохраняются в личной карточке после добавления в программу.
- В исходном каталоге нет иллюстраций. Видео открывается в Telegram; требуется доступ к закрытому каналу.
- Стартовые параметры 8–12 повторений и 3 подхода — значения для удобного заполнения, их нужно адаптировать под программу.

## Публикация

1. Перед обновлением открой СЕТ на телефоне и экспортируй JSON на экране «История».
2. Распакуй архив обновления. Загрузи **все файлы из корня архива** в корень существующего GitHub-репозитория, заменив файлы с совпадающими именами. Не загружай ZIP как файл.
3. Сохрани изменения коммитом в `main`; GitHub Pages опубликует файлы автоматически.
4. Открой сайт на телефоне с подключённым интернетом и дождись обновления service worker. Не очищай данные браузера и не удаляй ярлык для обычного обновления.
5. Проверь программы, историю, каталог, фильтр группы, добавление упражнения и экспорт JSON. Только после этого создай GitHub Release `v0.8.0-exercise-library`.

## Хранение пользовательских данных

Тренировки, программы, черновики, порядок упражнений и пользовательские настройки хранятся локально в браузере (`localStorage`, ключ `setlog-pwa-v1`). Серверной синхронизации между устройствами нет. Контрольные точки хранятся в IndexedDB (если доступно), но не защищают от очистки всех данных браузера. Регулярно храни JSON отдельно.
