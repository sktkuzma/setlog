Исправление: экспорт PNG и PDF восстанавливает мышечную группу для старых записей, где поле muscle отсутствует, по стабильным ID упражнениям в каталоге. Если группу определить нельзя, она не подсвечивается приблизительно.

В экспорт включаются только анатомические силуэты и маски фактически задействованных мышц. Блок «Примеры динамического выделения» и демонстрационные проценты не используются.

После публикации обновить сайт жёсткой перезагрузкой или закрыть/открыть PWA. Проверить PNG и PDF для одной тренировки и периода.

Данные пользователя, localStorage и Supabase не изменяются.
