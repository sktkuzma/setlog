# Проверка релиза СЕТ 1.0.1

- [ ] Скачать резервную копию данных перед обновлением.
- [ ] В настройках проверить равномерные отступы между разделами и карточками.
- [ ] В списке и на странице упражнения проверить, что изображения не обрезаются рамкой.
- [ ] Проверить, что карандашик компактный и не растягивается.
- [ ] Проверить логотипы Telegram и YouTube и переход по ссылкам.
- [ ] Для альтернативы упражнения добавить ссылку на видео через редактор и проверить её после повторного открытия карточки.
- [ ] Проверить наличие программ, записей истории и облачного состояния обоих аккаунтов.
- [ ] Проверить обновление приложения и открытие после включения авиарежима, затем автоматическую синхронизацию после восстановления сети.

Сценарии с реальным облаком и установленным Service Worker проверяются на опубликованном GitHub Pages.
