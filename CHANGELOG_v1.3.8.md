# СЕТ v1.3.8 — защита облачных записей и безопасные релизы

- Подтверждённая миграция Supabase: запись дневников и управление облачными снимками доступны через проверяющие RPC-функции, прямые операции изменения таблиц для клиентских аккаунтов закрыты.
- Публичные RPC сохраняют прежние имена и аргументы, поэтому клиентскому приложению не требуется миграция пользовательских данных.
- Прежние RPC-реализации перенесены в невнешнюю схему. Проверки авторизации, размера данных, конфликтов версий и резервного копирования сохранены.
- Перед изменением создана закрытая копия боевых таблиц, после изменения сверены контрольные отпечатки: записи дневников и облачные снимки не изменились.
- Файл начальной настройки Supabase защищён от повторного запуска на уже укреплённой базе.
- Прямая SQL-миграция, rollback и тесты на PostgreSQL 17 хранятся в `db-migrations/` и `db-tests/`. Все сценарии прошли GitHub Actions.
- GitHub Releases автоматически содержит ZIP обновления и полный ZIP для восстановления.
- Обновлены версия сайта, README и кеш PWA.

**Не изменялись:** схемы и данные тренировок, CSS, иллюстрации, внешний вид приложения, код PNG/PDF-экспорта.

Изменения Supabase уже применены к рабочей базе. Повторно выполнять миграцию без необходимости не требуется.
