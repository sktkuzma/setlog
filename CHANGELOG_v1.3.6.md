# СЕТ v1.3.6 — защита пользовательских данных

- Локальные резервные копии маркируются областью владельца и фильтруются по текущему дневнику; лимит 10 копий действует отдельно для каждой области.
- Старые копии без владельца остаются физически в IndexedDB, но не предоставляются другому аккаунту автоматически; для их миграции потребуется отдельная безопасная процедура.
- При изменении дневника во второй вкладке устаревшая вкладка прекращает сохранение и требует обновления страницы.
- Запоздавшие результаты синхронизации после смены аккаунта игнорируются.
- Ошибка обновления кеша не подменяет успешно загруженный из сети файл старой копией.
- Единая версия 1.3.6 в заголовке страницы и VERSION.txt.

Дизайн, CSS, генерация PNG/PDF, пользовательская схема и SQL Supabase не изменялись.

Перед установкой пользователь должен скачать JSON дневника. Ветка checkpoint-2026-11-08-v1.3.5-pre-hardening сохраняет исходный код до изменений.
