# СЕТ v1.3.11 — Прогресс 2.0

- На вкладке «Прогресс» добавлен выбор показателя: рабочий вес, e1RM, объём и повторения.
- Периоды: 7, 30, 90, 365 дней и всё время.
- Сравнение двух последних подходящих записей (включая разницу и проценты).
- Рекорды: лучший рабочий вес, оценочный e1RM, объём и веса на 5, 8 и 10 повторений.
- Аналитика вычисляется при чтении сохранённых подходов. Существующие записи, идентификаторы, схемы хранения и значения пользователей не переписываются.
- e1RM по формуле Эпли для 1–12 повторений, только при наличии положительного внешнего веса; результаты по упражнениям с пометкой bodyweight исключены.
- Новый интерфейс оформлен дополнительным CSS с сохранением существующей дизайн-системы.
- Оба новых ресурса включены в офлайн-кеш service worker.

Обновление не меняет текущие настройки пользователей, Supabase, черновики, историю и генераторы PNG/PDF.
Перед установкой обновления рекомендуется экспортировать резервную копию дневника JSON.
