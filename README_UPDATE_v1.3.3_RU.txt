SETLOG v1.3.3 — ИСПРАВЛЕНИЕ ЭКСПОРТА АНАТОМИИ

Что исправлено:
- PNG экспорт: анатомическая карта и легенда добавляются в длинную карточку.
- PDF экспорт: отдельная страница анатомии сохраняется для тренировки и периода.
- Новый Service Worker cache: setlog-cache-v22.

Как обновить:
1. Распаковать архив поверх текущего репозитория setlog-main.
2. Заменить одноимённые файлы.
3. Загрузить изменения в main.
4. После публикации открыть приложение онлайн и обновить страницу.
5. Проверить экспорт PNG и PDF отдельно для одной тренировки и периода.

Важно:
- Архив не содержит новых анатомических PNG: они уже должны быть установлены предыдущим обновлением v1.3.1.
- Не удаляйте и не очищайте localStorage.
- Ключ localStorage, схема данных и история тренировок не менялись.
- Проверка реального Canvas-рендера выполняется в браузере после публикации.
