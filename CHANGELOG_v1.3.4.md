# СЕТ v1.3.4 — исправление определения мышечных групп в экспорте

- PNG и PDF используют единый `resolveEntryMuscle()`.
- Для старых записей истории без `muscle` группа восстанавливается по `exerciseCatalogId`, `exerciseId`, `placementExerciseId`, затем по точному названию упражнения в каталоге.
- Анатомический экспорт по-прежнему рисует только нейтральную основу и реальные маски задействованных групп.
- Демонстрационные коллажи, примеры динамического выделения, проценты и фиктивные показатели в экспорт не добавляются.
- Service Worker: `setlog-cache-v23`; анатомические ресурсы включены в precache.
- Схема данных и `localStorage` не менялись.
