# СЕТ v1.3.7 — безопасное восстановление старых резервных копий

- Резервные копии без метки владельца автоматически сопоставляются только с вошедшим в аккаунт пользователем.
- Для сопоставления используется уникальный идентификатор сохранённой тренировки, присутствующей в текущем дневнике.
- Подтверждённые копии добавляются в список аккаунта без удаления оригиналов.
- Ранее созданные копии аккаунта не вытесняются, ограничение — десять видимых копий на аккаунт.
- Несопоставленные копии остаются скрытыми и физически сохранёнными.
- CSS, генераторы PNG/PDF, личные записи и SQL Supabase не изменялись.
- README, VERSION.txt и заголовок сайта синхронизированы.
