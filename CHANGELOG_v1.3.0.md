# СЕТ v1.3.0 — визуальный экспорт результатов

- PNG теперь представляет собой компактную оформленную карточку 4:5: отдельный вариант для одной тренировки и сводка для периода/выбранных упражнений.
- PDF состоит из отдельных страниц: сводка, графики фактических рабочих весов по упражнениям, прирост записанного рабочего веса, рейтинг суммы повторений и журнал либо подробные подходы выбранной тренировки.
- Прогресс сравнивается внутри одного и того же упражнения. График изменения веса строится только при наличии не менее двух записей с указанным рабочим весом.
- Рейтинг прироста показывает фактическое изменение максимального записанного рабочего веса и относительную разницу между первой и последней пригодными записями за выбранный период. Это сравнение записей, не медицинская оценка и не обещание прироста силы.
- «Больше всего повторений» сортируется по сумме фактически сохранённых повторений за выбранный период.
- В отчёты входят только данные, сохранённые в истории, а не незавершённые черновики или неиспользуемые элементы библиотеки.
- Объём считается только по подходам, где присутствуют и вес, и повторения; неполные подходы не трактуются как нулевой объём.
- В PNG/PDF не включаются время нахождения в зале и калории: приложение не собирает эти показатели.
- Формирование PNG/PDF выполняется локально в браузере. Схема данных и Supabase не менялись.
- Service Worker cache: v19.
